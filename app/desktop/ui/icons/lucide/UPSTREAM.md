# Lucide 0.468.0

The SVGs in this directory are unchanged copies from the
[Lucide 0.468.0 icon set](https://github.com/lucide-icons/lucide/tree/0.468.0/icons).
Keep the upstream [LICENSE](LICENSE) with any redistribution.

The desktop reads the icons as local CSS masks so they inherit the control's color.
The header and favicon use the project's existing `assets/campus-guardian.ico`.
