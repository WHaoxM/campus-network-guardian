# Security

This is a local Windows client for accounts you are authorized to use. The public checkout includes placeholder portal settings and loopback-only example credentials; neither the demo nor its tests need a real account.

Do not share `.env`, portal URLs with query values, cookies, HAR files, browser profiles, Windows user paths, or unredacted runtime logs in public issues. If a report involves sensitive details, open a minimal issue asking for a private reporting channel rather than posting the details.
