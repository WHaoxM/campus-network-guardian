# Windows 安装与使用

## 首次使用

下载 [v0.3.0 或更新的 Windows x64 ZIP](https://github.com/WHaoxM/campus-network-guardian/releases/latest)。包内已有 Python 和 Playwright，不用改 PATH、运行 pip 或下载 Chromium；电脑仍需要 Microsoft Edge 和 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/concepts/distribution)。

1. 完整解压 ZIP，再双击解压目录里的 `suse.cmd`，不要直接从压缩包预览运行。
2. 在弹出的目录选择器里选另一个空文件夹（也可以新建），可放 D 盘。**安装目录和解压目录不能互相包含。** 成功后记住安装目录；以后只用安装目录里的 `suse.cmd`，解压目录可以清掉。
3. 手动连上一次 **SUSE**，让 Windows 保存 Wi‑Fi 配置。填入校园网账号和密码，在「设置时段」里选至少一天并填写起止时间，然后点「保存并开启守护」。已点过保存但取消权限提示时，可在页面点「开启守护」重试，不必重新填写账号。备用账号在「账号管理」里添加。

开启后，计划任务负责启动后台守护；登录 Windows 后可从托盘打开窗口。关窗口不会停止守护。网络是否真的恢复以状态页为准；无人登录时的开机恢复取决于该电脑的 Windows 运行环境。

## 日常行为

在「状态 → 守护时段 → 编辑时段」随时修改，每周按北京时间重复，使用 24 小时制。结束早于开始时会延续到次日，例如周五 `22:30–01:00` 会守护到周六凌晨 01:00，即使周六没有另设时段。全天填 `00:00–24:00`。时段外仍可查看网络状态，不会自动重连、登录或主动下线。

时间栏可下拉选择，也可直接输入到分钟。几天的时段相同时，先设好一天，再点该行右侧的复制按钮，勾选目标星期并点「应用」。未勾选的日期不会改变；点「保存时段」才会写入设置。

保存后不必重启；后台读到新时段后，「等待后台应用」会消失。

在守护时段内，没有 Wi‑Fi 和外网时，守护器尝试连接已保存的 SUSE。其他 Wi‑Fi 不抢占；SUSE 地址没就绪不会提交认证。网络类认证失败可在「登录」日志看到 DNS 诊断，守护器不改系统 DNS，也不关闭 VPN。

## 旧版与卸载

- 若安装包没有 `suse.cmd`，请按[旧版安装说明](https://github.com/WHaoxM/campus-network-guardian/blob/v0.2.1/docs/INSTALL.md)操作。
- 如果维护时保留了旧版的 `campus.toml`，新版后台会沿用其中的时段，直到你在窗口里保存新设置。
- **从 v0.2.5 原地升级**：双击新版包的入口，选择原来含入口的安装目录；或运行 `.\suse.cmd upgrade "D:\你的原安装目录"`。不要解压覆盖。已启用开机守护时需要原 Windows 用户确认权限，只修改这个目录所属的 S4U 任务。
- 保留账号、时段、配置和浏览器资料。新版通过检查后才清掉本次旧程序，普通失败会回退。断电或强制结束留下的回退材料不会被静默清除。跨目录迁移不在本版本范围内。
- 需要停用时，请按[维护文档](DEVELOPMENT.md#停用与卸载)处理。停用不会主动下线或删除账号。
